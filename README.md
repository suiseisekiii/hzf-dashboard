# 杭州空气质量预报与观测

杭州 PM₂.₅、O₃ 国控站观测与 ProNet / FastForecast 模型预报展示平台。

[打开看板](https://suiseisekiii.github.io/hzf-dashboard/)

此仓库由数据服务器自动维护。main 保留网页代码与发布指针的正常历史；data-snapshot 保存完整当前网页、城市小时及日指标 CSV、最新逐站观测和组图，只有一个快照提交。数据变化后触发 Pages 发布；页面每 30 秒检查新快照，发布时间取决于 GitHub 部署进度。

所有时间均为北京时间。日统计使用小时结束标签 01—24 时；空白值表示缺测。各预报批次保留完整有效时效，首尾全缺测的占位时效不展示。历史订正随服务器实际保存的数据更新，页面底部显示快照时间。

逐时预报、七天日指标和模型评估使用同一项起报选择，可切换已保存的历史批次。日指标严格展示起报次日起连续七天：PM₂.₅ 为日平均浓度，O₃ 为日最大 8 小时平均浓度。尚未到达的观测标为待观测，当日完整日指标在自然日结束后更新。模型评估使用同一起报这七天内已到达的共同有效小时样本，计算 MAE、RMSE 和平均偏差。

网页源码和数据导出逻辑在源项目维护；直接编辑本仓库的生成文件会在后续发布时被更新。Pages 从 main 触发，部署时读取 data-snapshot 的最新完整快照。旧快照在本地回收，GitHub 远端旧对象由平台回收；首次历史提交保持不变。
