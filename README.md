# 杭城观气

杭州 PM₂.₅、O₃ 观测与 ProNet / FastForecast 预报展示。

[打开看板](https://suiseisekiii.github.io/hzf-dashboard/)

此仓库由数据服务器自动维护，包含网页、城市小时及日指标 CSV、最新逐站观测和组图。数据变化后触发 Pages 发布；页面每 30 秒检查新快照，发布时间取决于 GitHub 部署进度。

所有时间均为北京时间。日统计使用小时结束标签 01—24 时；空白值表示缺测。各预报批次保留完整有效时效，首尾全缺测的占位时效不展示。历史订正随服务器实际保存的数据更新，页面底部显示快照时间。

网页源码和数据导出逻辑在源项目维护；直接编辑本仓库的生成文件会在后续发布时被更新。
